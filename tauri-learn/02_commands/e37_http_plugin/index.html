说明

  • GET 默认请求 https://httpbin.org/get；POST 自动改用 /post
  • 非 2xx 演示：把 URL 改为 https://httpbin.org/status/404 后点 GET，显示 HTTP 404
  • 超时演示：v2 用 connectTimeout（毫秒，仅连接阶段）；timeout/readTimeout 是 v1 字段
  • 错误处理是本题知识点：网络不可达、超时、URL 不在 scope 内都会走到 catch
  • URL scope 在 capabilities 中配置（当前允许全部 http/https）
