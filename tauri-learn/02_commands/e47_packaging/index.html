各平台打包产物

  • W Windows：MSI（WiX 安装包）/ NSIS（exe 安装程序）
  • L Linux：AppImage / deb / rpm（按发行版选择）
  • M macOS：DMG / AppBundle（.app 目录）
  • → tauri build 默认只打当前平台；--target 交叉编译需要安装对应工具链

图标与体积优化

  • 1 cargo tauri icon <图片> 一张源图生成全套图标（回顾 E08）
  • 2 release profile 优化：lto / codegen-units = 1 / strip （可放在 workspace 根 .cargo/config.toml 统一生效）
  • 3 前端产物：vite build 压缩、按需引入依赖，控制 dist 体积
  • 4 包名规范：productName 不含下划线（Windows 打包对下划线不友好）
