练习 E29: 窗口状态持久化

tauri-plugin-window-state: 位置 / 大小 / 最大化自动保存与恢复

操作步骤：把窗口拖到任意位置、调整大小、最大化，然后点「保存」。 完全退出应用后再执行 cargo tauri dev 启动， 窗口会自动恢复到保存时的状态（插件在窗口创建时恢复、退出时保存）。

知识点

  • 1AppHandleExt::save_window_state(StateFlags::all())保存到磁盘
  • 2状态文件位于 app_config_dir.window-state.json
  • 3StateFlags 可单独控制 SIZE / POSITION / MAXIMIZED默认全选
