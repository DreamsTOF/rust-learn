练习 E48: 自动更新（updater）

tauri-plugin-updater：版本检查 → 下载 → 安装 → 重启

检查更新（check_update 命令）


        

          本练习没有真实更新源（endpoints 指向 example.com），预期显示检查失败的错误——
          错误信息本身就是教学点：生产环境需要自建更新服务器并提供
          latest.json + 对应平台的安装包与签名。
        

      


      

        
更新流程与配置

        
    
          
  • 
            1
            
              更新流程：检查版本 → 发现新版本 → 下载安装包 → 校验签名 →
              安装 → 重启应用
            
          
    • 
          
  • 
            2
            
              endpoints 模板变量：{{target}}（平台目标）、
              {{arch}}（架构）、{{current_version}}（当前版本），
              请求时会自动替换
            
          
    • 
          
  • 
            3
            
              pubkey 签名验证：更新包必须用对应私钥签名（minisign），
              未签名或签名不匹配的更新会被拒绝
            
          
    • 
          
  • 
            4
            
              配置位置：plugins.updater 段在
              tauri.conf.json 中（pubkey / endpoints）；命令通过
              app.updater()（UpdaterExt trait）获取实例
