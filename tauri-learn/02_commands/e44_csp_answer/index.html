内联样式演示（style 属性）

这个元素的样式写在 style 属性里（内联样式）

内联样式受 style-src 指令控制：答案版配置了 'unsafe-inline'，所以正常显示。如果去掉 'unsafe-inline'，WebView 会忽略该 style 属性并在控制台输出 CSP 违规警告（样式丢失、元素退回默认外观）。

CSP 指令逐条解读

  • 1 default-src 'self'：所有未单独指定的资源默认只允许来自应用自身
  • 2 style-src 'self' 'unsafe-inline'：样式表放行自身 + 内联样式。 很多 UI 框架（以及本页说明卡片）依赖内联样式，去掉 'unsafe-inline' 后页面样式会大面积失效
  • 3 connect-src ipc: http://ipc.localhost：invoke() 通过 ipc 协议调用后端命令，这两项缺失会导致所有命令调用失败
  • 4 img-src 'self' asset: http://asset.localhost data:：图片放行自身 + asset 协议 + base64 data URI

常见误区：connect-src 忘记写 ipc: 与 http://ipc.localhost 时，页面照常渲染，但所有 invoke 调用都会静默失败并报 CSP 错误，是最难排查的问题之一。
