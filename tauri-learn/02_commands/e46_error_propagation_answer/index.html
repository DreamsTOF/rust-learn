练习 E46: 自定义错误传播

thiserror 错误枚举 + 错误码 → 前端按 code 分类处理

触发后端错误（risky_operation）

前端统一通过 invokeWithError 调用：catch 到错误后直接读 err.code 分类展示（400 参数错误 / 404 未找到 / 500 服务异常）， 不再需要解析错误字符串。

这套链路是怎么工作的

  • 1 Rust 侧：#[derive(thiserror::Error)] 枚举定义错误变体， Display 消息即 #[error(...)] 内容
  • 2 错误码：AppError::code() 把变体映射为 HTTP 风格错误码（400/404/500）
  • 3 自定义 Serialize：命令返回 Result<T, AppError> 时， Tauri 要求错误类型实现 Serialize；这里把枚举序列化为 {"code": 400, "message": "无效输入: ..."} 对象
  • 4 前端分类：catch 到的对象带 code 字段， 映射为中文提示，避免前端猜测错误字符串
