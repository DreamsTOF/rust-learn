练习 E42: 主题切换

CSS 变量 / prefers-color-scheme / matchMedia / localStorage

选择主题

说明

  • 页面颜色全部由 CSS 变量驱动：:root 定义浅色变量，[data-theme='dark'] 覆盖为深色
  • matchMedia("(prefers-color-scheme: dark)") 检测系统主题
  • 「跟随系统」模式下，系统切换深浅色时页面实时跟随（change 事件）
  • 选择写入 localStorage：重启应用后仍是上次的选择
  • 切换本质是设置 <html> 的 data-theme 属性，无需重新加载页面
