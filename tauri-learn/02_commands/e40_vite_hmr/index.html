说明

  • devUrl 与 vite server 端口一致：tauri.conf.json 的 build.devUrl 是 http://localhost:1498，vite.config.ts 的 port 也要改成 1498
  • strictPort: true：端口被占用时报错退出，而不是自动换端口（避免 devUrl 失配）
  • HMR：修改 src/ 下源码即时热更新——改一下页面标题，应用不用重启
  • TAURI_DEV_HOST：局域网/移动设备调试时注入，Vite 监听该地址，HMR 绑定同一主机（端口 1421）
  • watch.ignored 排除 src-tauri 目录：Rust 代码变化不触发前端热更新
