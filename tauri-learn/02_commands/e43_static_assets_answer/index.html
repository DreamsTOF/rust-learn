public/ 目录资源

文件位于 public/tauri-logo.svg，用 src="/tauri-logo.svg" 直接引用

resource 目录

说明：三种资源使用方式

  • public/：原样复制到 dist，直接 /路径 引用（适合静态文件）
  • src/assets/：需 import 引用，打包时自动带内容 hash： 
    import logo from "./assets/logo.svg";
<img src={logo} />
  • 大文件/动态文件（如用户选择的文件）用 asset 协议： 
    import { convertFileSrc } from "@tauri-apps/api/core";
const url = convertFileSrc(filePath); // 磁盘路径 → asset:// URL
<img src={url} />
  • resource 目录是打包后存放额外资源的位置，运行时用 app.path().resource_dir() 获取
