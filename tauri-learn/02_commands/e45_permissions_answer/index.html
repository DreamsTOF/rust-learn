读写笔记（scope 内操作）


        

          教学点：越权按钮的目标路径 C:/Windows/win.ini 不在
          $APPDATA/notes/** 允许范围内，插件会直接拒绝——
          错误信息会包含 "path not allowed"。
        

      


      

        
这套权限是怎么组织的

        
    
          
  • 
            1
            
              capabilities/default.json：声明窗口 main 拥有哪些权限，
              这里引用 core:default + 自定义的 read-notes
            
          
    • 
          
  • 
            2
            
              permissions/read-notes.toml：自定义 permission 文件，
              identifier 写在 [[set]] 段里（这里是 read-notes）；
              内部以字符串列表引用插件的两个 permission
              （自定义 permission 文件不支持 allow 对象，scope 收紧在 capability 中做）
            
          
    • 
          
  • 
            3
            
              scope 收紧：capability 中以
              {"identifier": "fs:allow-read-text-file", "allow": [{"path": "$APPDATA/notes/**"}]}
              形式追加允许路径。$APPDATA 是应用数据目录变量，** 匹配任意子路径；
              不加 allow 时该 permission 的 scope 为空，任何路径都会被拒
            
          
    • 
          
  • 
            4
            
              最小权限：没有用 fs:default（它放开整个
              appData 目录），而是只放行 read/write-text-file 且仅限
              notes/**——越权演示证明目录外路径一律被拒
