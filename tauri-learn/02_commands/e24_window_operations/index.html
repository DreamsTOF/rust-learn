练习 E24: 创建与操作窗口

WebviewWindowBuilder 建窗 / set_position / set_size / center / 显隐切换

操控 ops 窗口

说明

  • 建spawn_ops_window：已存在 'ops' 窗口时直接 set_focus，不重复创建
  • 移set_position / set_size：用 PhysicalPosition / PhysicalSize 指定像素坐标与尺寸
  • 居center() 让窗口回到屏幕中央；is_visible() 判断后 hide / show
  • 关close() 会销毁窗口，之后可再次创建

我是 ops 窗口

通过主窗口的按钮可以移动、缩放、居中、隐藏或关闭我

  • 标本窗口 label 为 "ops"，与主窗口共用 index.html
  • 隐被隐藏后，主窗口「显示 / 隐藏切换」可再次显示
  • 关被关闭后窗口销毁，主窗口「打开 ops 窗口」可重新创建
