# 模块 02: 八道小菜

## 模块概览

模块 01 学会了"前后端通电话"。本模块开始做真正的应用——每课一道小菜，越做越复杂：

| # | 小菜 | 一句话需求 | 新增知识 | 前端 |
|--|------|-----------|---------|:--:|
| A01 | 待办清单 | 能加、能勾掉、能删的待办 | `manage` / `State<T>` / `Mutex`、结构体 + serde、`listen` / `emit` | Vanilla TS |
| A02 | 记事本 | 关掉软件字还在 | 路径 API、fs 插件读/写、`Result` 错误处理、React | React |
| A03 | 番茄钟 | 倒计时 25 分钟，到点提醒 | 异步命令 + tokio、通知、系统托盘 | React |
| A04 | 图片查看器 | 拖图片进来一张张翻 | 窗口操作、拖放、静态资源 | React |
| A05 | 记账本 | 记每天花了多少，看月度合计 | SQL 插件 | React |
| A06 | 汇率查询 | 今天 100 美元 = 多少人民币 | HTTP、Store 缓存 | React |
| A07 | 批量重命名 | 几百个文件批量改名，显示进度 | 后台任务、Channel 进度 | React |
| A08 | 剪贴板历史 | 复制过的都记下来，按快捷键翻出来 | 剪贴板、全局快捷键、菜单 | React |

> 每课"新增知识"只讲本课新学的；旧知识标注"沿用 a0X"，不重复展开。本模块八道小菜已全部完成 ✅
