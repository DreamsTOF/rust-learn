# 模块 01: 环境与第一个窗口

## 模块概览

本模块带你跑通 Tauri 开发的最小闭环：装好环境、创建项目、看懂目录、跑起第一个应用。

| # | 练习 | 新增知识 | 难度 |
|--|------|---------|------|
| 01 | 计数器 | `invoke`、`#[tauri::command]`、`generate_handler!`、serde | ⭐ |

## 练习代码

位于 `tauri-learn-v2/01_first_app/`，每个练习提供练习版（含 TODO）与答案版（完整代码）两个项目。答案版端口 = 练习版 + 1，可同时运行互不冲突。
