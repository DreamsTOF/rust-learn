 # Leptos 实战练习
 
 欢迎来到 **Leptos 实战练习**！这是一本通过动手练习学习 [Leptos](https://leptos.dev/) 框架的互动教程。
 
 ## 关于本书
 
 本书采用 **练习→解答** 模式：
 
 1. 每节先讲解核心概念
 2. 然后给出带有 TODO 提示的练习模板
 3. 最后提供完整的参考答案
 
 建议先独立完成练习，再对照答案巩固理解。
 
 ## 模块结构
 
 | 模块 | 内容 | 练习数 |
 |------|------|--------|
 | 01 基础与环境 | 组件、view! 宏、HTML 元素、条件渲染、构建器模式 | 20 |
 | 02 信号与响应式 | Signal、Derived Signal、Memo、Effect 等 | — |
 
 > 更多模块持续更新中...
 
 ## 环境要求
 
 - Rust (建议最新 stable)
 - [Trunk](https://trunkrs.dev/) (用于编译 WASM 应用)
 - 现代浏览器 (Chrome/Firefox/Edge)
 
 ## 快速开始
 
 每个练习都是一个独立的 Trunk 项目，可直接运行：
 
 ```bash
 cd leptos-learn/01_basics/e01_hello_world
 trunk serve
 ```
 
 然后在浏览器打开 `http://localhost:3001` 查看效果。
 
 ## 在线沙箱
 
 本书通过 CodeSandbox 提供在线沙箱，无需本地环境即可运行练习代码。点击每节中的沙箱链接即可打开。
