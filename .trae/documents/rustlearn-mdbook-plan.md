## 实施步骤

### 第 1 步：创建项目骨架

创建目录结构，编写以下文件：

| 文件                | 内容                                                     |
| ------------------- | -------------------------------------------------------- |
| `book.toml`       | mdbook 配置：标题、语言（zh）、作者、输出选项            |
| `theme/index.hbs` | 自定义 HTML 模板，增强`details` 标签样式，中文排版优化 |
| `src/SUMMARY.md`  | 23 章目录结构，每章指向对应`.md` 文件                  |
| `src/intro.md`    | 前言：项目目标、使用方法、前置知识说明                   |
| `src/appendix.md` | 附录：常见陷阱列表、Cargo 技巧、推荐资源                 |

### 第 2 步：逐章编写练习题（核心任务）

共 23 个 `.md` 文件，每个文件含 15-25 道题，总计约 460 题。

**每道题的标准模板：**

````markdown
### 练习 XX-YY: 题目名

> 难度：⭐ / ⭐⭐ / ⭐⭐⭐
> 类似 C++ 的 XX / 类似 Java 的 YY

题目描述（1-2 句说明要做什么）

```rust
fn main() {
    // 第一步,定义一个变了
    // 第二步，定义一个新变量=原变量
    // 第三步，打印新变量
}
````

<details>
<summary>点击查看参考答案</summary>

```rust
fn main() {
    let x = 42;          // 第一步,定义一个变了
    let y = x;           // 第二步，定义一个新变量=原变量
    println!("{}", y);   // 第三步，打印新变量
}
```

**说明：** 为什么这样写，关键知识点解释。

</details>
```

**难度分布规则（每 5 题一组）：**

| 题号偏移 | 难度   | 提示量            | 补全程度       |
| -------- | ------ | ----------------- | -------------- |
| +0       | ⭐     | 每行都有详细 TODO | 只需填空       |
| +1       | ⭐     | 每行都有详细 TODO | 只需填空       |
| +2       | ⭐⭐   | 每行都有详细 TODO | 补全 50%       |
| +3       | ⭐⭐   | 每行都有详细 TODO | 补全 50%       |
| +4       | ⭐⭐⭐ | 每行都有详细 TODO | 几乎全部自己写 |

## 关键决策

1. **纯 mdbook，无需** **`exercises/`** **目录**：题目直接在 `.md` 文件中以 `rust` 代码块呈现，用户复制到本地或在线编辑器中练习。不创建可运行项目，避免 Cargo workspace 维护成本。
2. **`<details>`** **标签折叠答案**：原生 HTML，零依赖，mdbook 完全支持。
3. **中文注释引导**：所有 `// TODO:` 注释用中文写，描述意图而非实现。
4. **C++/Java 对照**：在关键差异处用 `> 类似 C++ 的 XX / 类似 Java 的 YY` 标注。
5. **`theme/index.hbs`** **自定义**：仅添加 details 标签的 CSS 样式（过渡动画、内边距等），不改动主布局。

## 验证
