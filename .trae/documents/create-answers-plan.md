## 答案文件夹规范

每个答案文件夹结构：

```
e{NN}_{name}_answer/
├── Cargo.toml          # package.name = "eNN_name_answer"
├── index.html           # <title>练习 NN — 参考答案</title>
└── src/
    └── main.rs          # 完整可编译代码（无 TODO）
```

- 与练习同目录但加 `_answer` 后缀
- `trunk build` 零错误零警告
- 无任何 `TODO:` 或 `FIXME:` 标记
- 注释保留以帮助理解

### 模板示例

**CSR (Ch1-Ch6, Ch8):**
```rust
// ============================================================
// 练习 NN: 题目名称 — 参考答案
// ============================================================

use leptos::prelude::*;

#[component]
fn Exercise() -> impl IntoView {
    // --- 完整实现，无 TODO ------------------------------------
    let (count, set_count) = signal(0);

    view! {
        <div>
            <p>当前值: {count}</p>
            <button on:click=move |_| set_count.update(|c| *c += 1)>
                "增加"
            </button>
        </div>
    }
}

fn main() {
    mount_to_body(Exercise);
}
```

**SSR (Ch7):** 使用 cargo-leptos 结构（lib.rs + main.rs）

## 执行流程

每 agent 执行以下步骤对 batch 内的每道题：

1. **读取练习文件** `eNN_name/src/main.rs`，理解题目要求
2. **创建答案目录** `eNN_name_answer/`（含 Cargo.toml、index.html）
3. **编写答案 main.rs** — 完整可编译代码（无 TODO）
4. **编译验证** `trunk build` 通过
5. 进入下一题

### 编译验证

- 第 1-6 章、第 8 章：`trunk build`（CSR）
- 第 7 章 SSR：注意需要 cargo-leptos 结构（lib.rs + main.rs）

## 注意事项

1. **不要修改练习文件** — 只创建和修改 `_answer` 文件夹
2. **不要修改 Cargo.toml** — workspace members 都已预注册
3. **确保编译通过** — 每题答案必须通过 trunk build
4. **保持命名一致** — 答案文件夹名 = 练习名 + `_answer`
5. **Cargo.toml edition 使用 2024**（与现有练习一致）
6. **答案代码完全独立** — 不含 TODO 标记
