# 前言与使用说明

## 这个项目是做什么的？

这是一个面向 **有 C++/Java 基础、熟悉 Rust 基本语法但缺乏实战经验** 的开发者设计的练习集。包含 **460 道** 练习题，覆盖从所有权到并发编程的 23 个主题。

## 前置知识

- 了解变量、函数、控制流等基本编程概念
- 知道 Rust 的基本类型（i32, f64, bool, char 等）
- 听说过所有权（ownership）概念
- 有 C++ 或 Java 的实际编程经验

## 如何学习

1. **顺序做题**：建议按章节顺序进行，每个主题建立在前一个主题之上
2. **每题先自己写**：阅读题目和代码框架，在本地或在线 Rust Playground 中尝试补全
3. **想不通再看答案**：点击 `<details>` 标签展开参考答案，理解后再继续
4. **动笔写**：只看不写等于没学，一定要亲手敲代码

## 题目格式说明

每道题包含：
- **难度标识**：⭐ 简单 / ⭐⭐ 中等 / ⭐⭐⭐ 挑战
- **C++/Java 对照**：在关键概念处提示与 C++ 或 Java 的异同
- **TODO 注释**：用中文描述要做什么，但不给代码实现
- **折叠答案**：`<details>` 标签包裹的完整参考答案

## 难度递进规律

每 5 题为一组：
- 第 1-2 题：⭐ 简单，每行都有详细 TODO，只需填空
- 第 3-4 题：⭐⭐ 中等，部分 TODO，需要补全 50% 左右
- 第 5 题：⭐⭐⭐ 挑战，少量提示，几乎全部自己写

## 代码块说明

书中的所有 `rust` 代码块都是**不可运行的示意代码**，供阅读和参考使用。
建议将代码复制到本地 Rust 环境或 [Rust Playground](https://play.rust-lang.org/) 中实际运行和修改。
